## About the Project
Student Task Manager is a simple Python application that helps students organize and manage their daily tasks.
## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Handle invalid inputs
## Technology Used
- Python
## How to Run
1. Install Python on your computer.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run `python task_manager.py`.
## Learning Outcomes
- Practiced Python lists and dictionaries.
- Learned loops and conditional statements.
- Improved problem-solving skills.
